In diesem Kurs lernst du, Webseiten selbst zu bauen. Du strukturierst Inhalte mit HTML, gestaltest sie mit CSS für alle Bildschirmgrößen und machst sie mit JavaScript interaktiv.

Der Kurs läuft live-online an zwei Abenden pro Woche in einer festen Gruppe. Dozenten mit langjähriger Praxis erklären jedes Thema an Beispielen, danach probierst du es direkt im Live-Unterricht aus und wir besprechen die Ergebnisse gemeinsam. Fragen klärst du direkt live. Die Unterlagen bekommst du zum Download.

Der Kurs passt zu dir, wenn du verstehen willst, wie Webseiten funktionieren, und eigene Seiten umsetzen möchtest – im Beruf oder für eigene Projekte.
